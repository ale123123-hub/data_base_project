# 🏥 Medical Clinic Database Management System

A relational database system designed and implemented in **SQL Server (T-SQL)** to manage patient prescriptions, medical staff, and medication inventory.

---

## 📌 Features & Architecture

- **Database Normalization:** Structured schema to handle doctors, patients, prescriptions, and medication stock efficiently without redundancy.
- **Data Integrity:** Foreign key constraints and relational mapping for multi-medication prescriptions.
- **Complete SQL Pipeline:** Divided into modular scripts for structure, sample data, and business logic.
